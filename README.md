# Z Cyber Security Event Radar

Static monthly calendar for US-based security, fintech, and healthcare events.

## Share Links

After GitHub Pages is enabled, use:

- Calendar: `https://rutvigtm.github.io/zcyber-event-calendar/`
- ICS: `https://rutvigtm.github.io/zcyber-event-calendar/zcyber_security_events.ics`

Events on the monthly calendar open their original source pages in a new tab.
